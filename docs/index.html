ora-plan

Readable Oracle execution-plan explanations

Example input

| Id | Operation          | Name      | Rows | Cost |
|  0 | SELECT STATEMENT   |           |   10 |   12 |
|* 1 | TABLE ACCESS FULL  | CUSTOMERS |   10 |   12 |

Example output

1. TABLE ACCESS FULL on CUSTOMERS

Meaning:
Oracle is scanning table blocks rather than using an index access path.

Review:
Valid for small tables or large-result queries; review when selectivity and table size make the access path worth investigating.
